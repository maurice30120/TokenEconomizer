# Injected block: one budget, credited injections, docs that follow the code

What a session receives as micro-skills is one block, whatever layers compose it. The caps a
person configures apply to that block, the block records which facts it carried, and a fact the
session was given is credited when the waste it prevents never occurs. The documentation states
this behaviour; where it disagreed with the code, the documentation changed, not the code.

Found while running the CodeTour campaign on 2026-11-25: the campaign announced "4 facts, 150
tokens" and a session received 5 facts and ≈330 tokens, `injected_ids` was always empty, and the
Knowledge glossary still said Knowledge is never given at session start.
